# MessageWeave Chat App Example

A small, runnable chat app built around the `messageweave` engine.

MessageWeave provides the durable room/event/sync primitives. This example supplies
the host-app pieces around it:

- a TypeScript Node HTTP server for transport
- Server-Sent Events for live delivery
- a TypeScript browser UI for room creation, joining, and sending messages
- a persistent SQLite database stored at `data/messageweave.sqlite`
- demo-only in-process SSE client tracking

The example uses `better-sqlite3`, Drizzle ORM (`drizzle-orm`), `drizzle-kit` for migrations, and MessageWeave's built-in `drizzleAdapter` (`messageweave/drizzle`).

## Event-Sourced Operations

MessageWeave persists all actions as immutable events (`FlowEvent`) and links parent/child relationships via `eventEdge`:

- **Sending a message (`message.text`)**: Publishes a new event assigned a monotonic `sequenceId`.
- **Editing a message (`message.edit`)**: Publishes a revision event linking back to the target message via `eventEdge` (`parentEventId`) and `content.targetMessageId`.
- **Deleting a message (`message.delete`)**: Publishes a tombstone event targeting the original message.
- **Client Synchronization**: Real-time sync streams fetch events using `sinceSequenceId`.

## Run

From the repository root:

```bash
pnpm install
pnpm -C examples/chat-app dev
```

Then open `http://localhost:5173`.

The source lives in `src/server.ts` and `src/client.ts`. `pnpm -C
examples/chat-app build` compiles them to `dist/`, and the server serves the
compiled browser script at `/app.js`.

Delete `examples/chat-app/data/messageweave.sqlite` to reset the demo database.

Set a display name in two browser windows and join the same room to try a live
conversation.

## Schema & Migrations

The Drizzle schema at `src/db/schema/messageweave.ts` is generated by the `@messageweave/cli` package:

```bash
pnpm -C examples/chat-app schema:generate
```

That script runs:

```bash
messageweave schema generate --format drizzle --dialect sqlite --out src/db/schema/messageweave.ts
```

SQL migrations are generated by `drizzle-kit`:

```bash
pnpm -C examples/chat-app migration:generate
```

The server automatically applies pending migrations on startup using `migrate()` from `drizzle-orm/better-sqlite3/migrator`. You can also run the migration explicitly:

```bash
pnpm -C examples/chat-app db:reset
pnpm -C examples/chat-app db:init
pnpm -C examples/chat-app dev
```

Storage is configured using the built-in `drizzleAdapter`:

```ts
import { drizzle } from "drizzle-orm/better-sqlite3";
import { createMessageWeave } from "messageweave";
import { drizzleAdapter } from "messageweave/drizzle";
import * as schema from "./db/schema/index.js";

const database = drizzle(sqlite, { schema });

const flow = createMessageWeave({
  storage: drizzleAdapter(database, { provider: "sqlite", schema }),
});
```
